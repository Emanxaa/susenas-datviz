# Variable Discovery Prompt

Tujuan penelitian: "{OBJECTIVE}"

Gunakan metadata.db sebagai sumber kebenaran.

Lakukan langkah berikut.

1. Identifikasi konsep penelitian.
2. Tentukan level data (rumah tangga atau individu).
3. Cari seluruh variabel relevan di variable_registry.
4. Verifikasi dengan label resmi.
5. Cek kompatibilitas tahun.
6. Tampilkan variabel wajib dan pendukung.
7. Sertakan sumber metadata.
8. Jangan mengarang variabel.
